# v1.7.3 界面精修

## 方向

- 产品：给 TeamSpeak 频道用户使用的语音悬浮窗，设置应便于快速调整并返回通话。
- 性格：安静、清晰、精确，沿用现有浅色与绿色品牌。
- 语境：语音控制面板与频道状态，不采用营销页或数据看板布局。
- 视觉重点：真实成员预览与发言状态，外围控件保持克制。
- 识别细节：现有三条声量条；保留头像光环与功能性说话动效。

## 按 unslop 小范围精修的九轮处理

1. 间距：设置页顶部三行由 202 压缩到 168 个逻辑像素，页脚由 64 改为 56；统一内容边距，保留五类设置和各自滚动位置。
2. 配色：保留白色、浅灰和绿色；文字、按钮使用更深的绿色，亮绿色仍用于语音预览。普通主按钮白字对比度由约 2.54:1 提升到 4.5:1 以上。
3. 图标：复用已有图标，托盘图标统一为 1.5 线宽；不引入新图标库或装饰图标。
4. 文案：保留现有七种语言及分类、功能名称，不增加新功能或营销文案。
5. 字体：保留系统字体与中韩文字体回退，说明文字统一到 13/20，数值使用等宽数字；日志保留等宽字体。
6. 布局：只调整现有栏高与比例，预览栏由 300 调整到 280；日志工具栏在窄窗口中换行，避免操作按钮重叠。
7. 细节：设置与日志窗口共享按钮、颜色、标题、关闭按钮与焦点样式；托盘保持现有独立的图标和文本列。
8. 视觉：保留现有真实软件预览，不生成图片，不引入网页运行时；日志截图仅使用虚构测试数据。
9. 动效：不增加入场、循环或装饰动效；悬浮窗的发言反馈保持不变。

## 范围

本次仅调整设置、日志和托盘的视觉；不修改 TeamSpeak 通信、静默重连、通知、启动项、服务器选择或悬浮窗行为。未自动更新桌面快捷方式或发布 GitHub Release。
